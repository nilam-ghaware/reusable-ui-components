# Reusable UI Components — Demo Library

Small Angular project demonstrating two reusable components (Button, Card).

Quick start

- Prerequisites: Node.js (16+), npm, Angular CLI (optional).
- Install dependencies:

```bash
npm install
```

- Run dev server:

```bash
npm run start
# or: ng serve
```

Open http://localhost:4200 and view the demo page.

Build

```bash
npm run build
# or: ng build --prod
